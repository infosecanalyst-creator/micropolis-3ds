# Changelog

## 2026-11-27

- Your city can no longer be replaced by one tap. NEW CITY, a scenario and LOAD CITY ask first (NO is chosen, B cancels), and the city in play is kept as its own file before it is replaced. LOAD CITY lists the last save and the kept "Earlier" cities with date, population and money.
- A scenario's goal and time limit now survive exit and restart.
- All 16 tools are one tap away: the last slot of the tool strip is More, L / R past the end of the strip open the same grid, and the grid works with the D-pad and A.
- START menu in the house order, one column: RESUME, MANUAL, SAVE CITY, LOAD CITY, NEW CITY, SETTINGS, EXIT GAME. SETTINGS has LEFT HAND and DISASTERS. Menu hints follow left-hand mode. B goes one step back everywhere.
- Disasters ask before they start.
- A new city opens on land, not open sea. Building on water says "Can't build on water here."
- B (bulldozer) says which tool you now hold. The speed button shows Pause / Slow / Med / Fast. Clearer R C I demand bars. Overlays keep the land outline on the minimap.

## 2026-11-21

- If the saved city will not load at start, the game opens the previous save (autosave.cty.bak) or a new city, says so, and moves the unreadable file aside instead of overwriting it.
- Disasters and other important messages now also show on the touch map, not only on the top screen.
- Smoother: no extra right-eye picture is made when the 3D slider is down, and the city's clock follows real time.

## 2026-11-20

- Timed autosave every 5 minutes of play; HOME > Close saves the city.
- Install path: the program is /3ds/micropolis.3dsx. The START menu shows the build version.
- The game no longer waits out a fixed 3 seconds for memory at start.

## 2026-11-19

- Saves are safer: written to a temporary file first with the old one kept as .bak, failures are reported, and EXIT asks before quitting after a failed save.
- The overlay key says low / high, off / on, fall / rise in words, not only colour.
- Manual: drag the stylus to scroll the text, with a little momentum.
